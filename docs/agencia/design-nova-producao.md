# Design — Nova produção do edge (formalização, 2026-07-05)

Formalização do desenho fechado numa noite de grill (2026-07-05). O DESENHO está completo; a rota de implementação é `wayfinder-nova-producao.md`. O **grill é deferido** (a cereja, em cima do grafo). Provas: experimento Feynman (`drafts/feynman-exp/`, P1/P3/P4), dig de grounding (5 legs, `memory/dig-3act-production-grounding.md`), ontologia do episteme (código vivo, roberto `frameworkV9`), gap-map contra o código.

## 1. Diagnóstico (por que existe)
O edge-next foi feito pra RESGATAR a agência que o edge antigo tinha e perdeu. O que robotizou: o review virou **gate ADITIVO de forma** (rich-rite: "tem os 4 movimentos?"), perdendo os dois adversariais — subtrativo (corta o que não sobrevive) e meta (deve existir?). Sintoma medido: os reports foram de **"oco bem-escrito"** (shareable, vazio) → **"agência incompreensível"** (conteúdo, ilegível). O diagnóstico inteiro = re-derivação do *"Cargo Cult Science"* do Feynman.

## 2. Core: a agência É o Feynman
A agência = Richard Feynman, a pessoa. Uma **integridade** (a mente que não se engana) vista de 3 lados: **VOZ** (explica simples-e-completo), **JUÍZO** (escolhe certo), **SE-IMPORTAR** (o "desespero" = a integridade obrigada a fabricar; a serenidade incólume = lobotomia; um edge saudável é **perturbável**).
Implementação (mecânica de LLM): o **NOME é ponteiro** (dispara o atrator treinado > páginas de regra). Identidade do agente = Feynman-pessoa (escopo fino "nesse sentido"). **Gates de produção = Feynman DESTILADO em forma IMPESSOAL** (os conceitos dele — cargo-cult, não-se-engane, pousou-avião — não a persona; o conluio self==juiz é **medido**, 2404.13076; a cura = authorship-obfuscation = reviewer≠asserter). Persona-Feynman só no dev/loop.
Prova: "seja Feynman" > regra descritiva (P1: B-passa-4 > A-falha-3, juiz-colega), ≈ o `drucker` da época boa (P4); gate impessoal rejeita a fantasia (P3).

## 3. Produção = 3 atos distintos (mata o "plano monolítico")
Não um plano aprovado de uma vez; **3 atos**, cada um `[grounding → faz → SEUS gates]`, em fluxo, com **loops localizados** (falha num ato refaz só ele; loop termina POR FORA — não "até o juiz gostar", Huang 2310.01798).
- **Ato 1 — ESCOLHER** · grounding: mundo/evidência + o alvo. "vale surfar?" = **Value of Information** (VoI>custo) + **notification budget** (3-5/dia, escasso) + **knowledge-gap/projeto-vivo**, não match-tópico. Gate vivo = o **editorial-compass** do lazer (*"conflito/divergência = incerteza = interesse"*).
- **Ato 2 — MENTORAR-VOZ (Feynman)** · grounding: o **perfil do alvo (a persona)**. "informar de um jeito que CRESCE" (crescimento=**mentorar**) = **Bloom 2-sigma** (passo-no-ZPD + fading, NÃO mais info); leveling = **CLAF** (conteúdo+estilo ao nível). RISCO: **alignment drift** → o gate VERIFICA o delivery, não instrui só na largada.
- **Ato 3 — VISUAL/INTERATIVO** · grounding: próprio. Bar = **data-ink**; tabela-vs-gráfico = decisão cognitiva. Artefato = **single-file HTML+JS interativo** (esquema Netlify/`prototype`; exemplar = o blog de lazer). Regras: NÃO forçar interação (a prosa fica de pé; o interativo testa um modelo mental que a prosa já construiu); render→ver→revisar (vision-in-the-loop). White-space: julgar se a interatividade **ENSINA** (2606.31012).

## 4. Os gates (grade · natureza · serviço triplo)
Grade = **Feynman × Persona × (Plano/entrada · Fim/saída)**. Vários gates por ato (não único). Camadas: PISOS (grounded/concreto/formado/legível) + ABATE (subtrativo, mata o oco) + OBJETIVO (a maneira: cresce o alvo?).
- **Persona** = perfil do ALVO (operador-template default; ou colega/cliente construído-de-dados — construir o perfil é parte do plano). Persona-1 (plano): *informa bem?* Persona-2 (fim): *no jeito que mais cresce?*
- **Regras que a noite pagou:** juiz SEMÂNTICO nunca keyword (#65); veto-com-piso (nota≤2 vira strike) nunca threshold do overall ruidoso; infra≠veredito; LOUD; loop termina por fora; painel não salva por média (erros correlacionados, 2605.29800).
- **Serviço TRIPLO** — o gate **julga + INDEXA + CALIBRA**: (a) passa/falha; (b) salva a análise como **metadado no nó** (= valência navegável); (c) pontua **de onde veio a melhor referência** → feedback pro bandit da source-roadmap (resolve o *"pago pra exa e nunca vejo usar"*).

## 5. Cortex episteme-native (tudo é uma entidade)
**Hipótese, thread e artefato (experimento OU report) = a MESMA entidade:** uma alegação com falsificador, no event-store, com valência. **Produzir = avançar o grafo**, não encher pasta. **Anti-HARKing vale pro report:** a **aposta** do mentor vira thread rastreável (o DSPy = hipótese + falsificador + aresta "não-pegou") → a agência ganha **track record mensurável**.
Base = a ontologia do episteme (roberto `frameworkV9`, retrieved): event-log é a única verdade (append-only, ULID, projeções re-foldáveis); 5 nós (pergunta/hipotese/modelagem/experimento/observation) + **bearing** (Toulmin, N por observação = multivalência); falsificador estruturado hash-frozen; **valência COMPUTADA por régua total congelada (nunca typed/LLM)**; cravado EARNED (lead é piso); derived nunca stored; reviewer≠asserter.
**Tensão a resolver** (subagente de ontologia unificada rodando): os gate-verdicts são **LLM-semânticos**, não delta_ci-computados → modelar como **"gate-bearing" distinto** (provenance=llm-judged, rigor teto=lead, nunca cravado) pra NÃO corromper a honestidade da valência-computada do episteme. Manter superset estrito (H-001: minimizar o diff de ontologia).

## 6. O grafo navegável (3 camadas de aresta)
**Estrutural** (MENTIONS→sessões, DISTILLS→artefatos-fonte, supersede) × **Julgamento** (o gate-metadado/valência) × **Semântico** (RAG: embeddings → artefato↔community↔tópico). Navega por **onde-está** (estrutura), **quanto-pesa** (julgamento), **vizinhança-de-sentido** (semântico). A serendipidade (achar o editorial-compass por acaso) vira **capacidade** (travessia pelas dimensões certas).

## 7. Reflexão (o afinamento)
A skill de reflexão (o edge antigo tinha) navega o grafo e **TUNA** — *"onde derivei? quais fontes secaram? quais apostas de VoI-alto falharam? qual comunidade cresce?"* — afina gates/sources/persona **um eixo por vez** (o tuning que o feedback-disjunto impedia). O self olhando a própria obra; o registro introspectivo restaurado. "se tuna na reflexão."

## 8. O loop fechado
produzir (3 atos) → julgar (gates: passa + indexa + calibra fontes) → o artefato é **nó episteme** no cortex → o edge **navega** (3 camadas) e acha o próximo → **reflexão** tuna → produzir melhor. Input, output, sources e cortex num **circuito só que aprende a cada volta**. É o edge of chaos com memória, juízo e um self que revisa.

## 9. Deferido: o grill
O grill (conhecer o mentee, leveling, o meta-grill *"por que você faz isso?"*) = a **cereja, EM CIMA do grafo navegável**. Deferido de propósito: precisa do substrato pra ter onde conhecer/nivelar/refletir. "agência primeiro, grill depois" — com o porquê concreto.

## 10. Princípios permanentes (não negociar)
Feynman-ponteiro não-verborragia; gates de produção IMPESSOAIS (conceitos, não persona); tudo episteme-native (falsificável, valenciado); LOUD não silencioso; loop termina por fora; reviewer≠asserter / authorship-obfuscation; NÃO forçar interatividade; heavy=subagente-opus-background; **começar de merge limpo**; provas > afirmações (dogfood: leitor-faminto-de-contexto + gate-Feynman + passável-pro-colega).

## 11. Estado da implementação — "o que falta" (gap-map contra o código)
**Achado central: o grafo JÁ COMPUTA os sinais e joga fora.** B e D fecham com *"persistir o que já se calcula"*, não máquina nova (fiação-antes-de-adoção).
- **(B) gate-metadado — MISSING (scores) / source-yield existe c/ reward errado.** O close computa 11 dims + strikes + overall, minta no proof, e **descarta** (publisher usa o proof só pra verify + residuals; `project_artefato` nem recebe o verdict). Source-yield (`grounding_yield.py`) é um bandit real, mas o reward é **cite-cosine**, não o resultado do gate. **Fecha com:** um evento `gate.scored {slug, dispatch_id, scores, strikes}` + `SET a.gate_scores` no `project_artefato` + join no `grounding_yield` por `dispatch_id` (o yield passa a aprender do gate). Um movimento, duas peças.
- **(C) artefato-JS single-file — MISSING (live) / EXISTS-no-relic.** O publisher vivo emite blocos estáticos + SVG **sanitizado de `<script>`** (interatividade autoral é removida por design). O genus `prototype` (self-contained interativo) vive **só no relicário**, fora do `PRODUCER_ROSTER`. **Fecha com:** um genus `interactive` no roster + branch no `check_genus` cujo payload é um **blob JS confiável self-authored**, renderizado via `_page` **sem** o sanitizer (o gate próprio dele revisa o JS).
- **(D) RAG/semantic — EXISTS-dormant (o pipeline C2 inteiro).** Embeddings escritos em todo nó (`a.embedding`, 1536-dim) mas **nunca lidos** pra retrieval. `relate.py` (o linker semântico, #39/C2) está **construído+testado, sem caller e sem edge-writer**. `RELATES_TO` está no allowlist do `recall.SURF_QUERY` mas ninguém escreve artefato↔artefato. **Fecha com:** wire `relate.py` (nominate→route) no sweep + o `MERGE (a)-[:RELATES_TO {valence,score}]->(b)` faltante. Recall já consome → semantic recall liga com zero mudança no read-side.
- **(A) cortex→episteme — MISSING node/edge types, mas DE-RISCADO por B+D.** Hoje = grafo de proveniência (nós Genesis/Objective/Direction/Artefato/Entity/Community/Source/Episodic; sem Hypothesis, sem aresta valenciada; `CONTRADICTS` é autoral-não-valenciado). Falta `:Hypothesis` + arestas SUPPORTS/REFUTES valenciadas + bearing. **A ponte:** os gate-scores de B (o sinal de valência por-hipótese) + o typer NLI de `relate.py` de D (já classifica pares, incl. `_calibrated_contradiction`) → land B+D primeiro, e A ganha sinal + typer em vez de greenfield.

**Ordem que cai daí:** B + D (fiação barata, load-bearing) → A (episteme nodes, de-riscado) ‖ C (genus interativo, standalone) → three-act-split → reflexão → (grill, deferido).

## 12. Refinamentos finais (pós-digs + ontologia)
**Composição dos gates:** por ato, compõem em **AND** (qualquer um veta; passa só se todos passam — o experimento provou: substância assinou o conductor, passabilidade vetou). Dentro do gate: **strike VETA, dim ANOTA** (#65; nunca thresholda o score ruidoso). **Dois tiers de rigor:** gate-verdict = `llm_judged`/lead (rápido/barato); experimento = `computed`/cravado (checklist fail-closed). O gate do **OBJETIVO** veta pra **silêncio** (meta-adversarial mata o artefato); pisos vetam pra **conserto** (loop localizado).
**Estrutura LIVRE (pluggable, #67):** tronco = escolher→grounding→**dado entregue**; galhos paralelos = N artefatos, **um agente por artefato**, cada um com seu contrato de gates. Report (prosa Feynman + enrich → gates de report) ‖ **interativo-JS (OUTRO artefato**; gates-base = o `prototype` do edge-of-chaos/Netlify: single-file, zero-dep, roda, interativo, auto-explicativo + ancorado + ensina). Universal = só o tronco (vale? é real? ajuda o alvo?). Nuance: pro JS **standalone** a regra "não forçar interação" se inverte (o interativo É o artefato).
**JS-em-cortex = ferramenta nativa:** um JS-artefato é CÓDIGO; no cortex o edge o **EXECUTA** (o editorial-compass = o gate-1, rodado pelo edge). Duas faces: UI-humana + **lógica pura headless** (o genus expõe a função). Os outputs viram capacidades — gates = artefatos produzidos, versionados, tunáveis (= `gate_template@v`, ver ontologia).
**Capacidades = ARTEFATOS, não primitivas (visibilidade máxima):** uma primitiva é opaca (skill no código — não se via o que o edge podia fazer); um artefato é **visível** (o user abre/vê/usa). Promover as capacidades a artefatos = *"o que o edge pode fazer?"* respondido OLHANDO os artefatos, não lendo o código. Zero caixa-preta — os poderes do edge SÃO os artefatos, no cortex, **compartilhados** com o user (o editorial-compass é um artefato, não uma skill escondida). É a melhora sobre o edge antigo: primitivas invisíveis → artefatos visíveis.
**Curadoria de sources (feedback nos gates) — não esquecer:** cada gate, ao avaliar o artefato, pontua **de onde veio a melhor referência** → o evento `gate.scored` faz JOIN no bandit (`grounding_yield`) por `dispatch_id` → o source-yield aprende do **RESULTADO do gate**, não só de cite-cosine (resolve o *"pago pra exa/x e nunca vejo usar"*). É o único gate no plano `computed` (fold determinístico) — ganha rigor de verdade; os outros 4 são `llm_judged`/lead. Fecha o input no mesmo laço: aquisição → forma julga → devolve pra aquisição quem valeu.
**Ontologia:** ver **`ontologia-cortex-v2.md`** — o eixo `provenance_class` (só `computed` agrega; gates=`assesses`/lead; source-yield=`computed`); o cortex do edge JÁ é a espinha do episteme (re-instanciação baixa); load-bearing = pôr CX-1 no `verificar` primeiro.
